# Matrix Ender

The ultimate combination of MATLAB and PyTorch. This matrix CLI utility allows users to test their models on the fly without having to rewrite complicated PyTorch boilerplate. On a more basic level, this CLI utility also contains a handful of built-in algorithms for solving common linear algebra problems without writing specialized programs.
